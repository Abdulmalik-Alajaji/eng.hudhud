# data/

بيانات الكلية بصيغة JSON. كل ملف هنا يُضمَّن في الموقع وقت البناء، ويُفحص آلياً قبل كل نشر (`src/data/validate.ts`): أي خطأ يوقف النشر برسالة بالعربية تذكر الملف والمكان.

**كل البيانات الحالية تجريبية** (`"demo": true`) ومن اختراعنا للتجربة فقط. ما دام فيها عنصر تجريبي واحد يظهر في أعلى الموقع شريط «نسخة تجريبية: البيانات ليست حقيقية». البيانات الحقيقية تأتي من الفريق فقط، ولا تُخترع.

## الفكرة

الكلية «شبكة»: على خريطة كل طابق **نقاط** (عند التقاء الممرات وعند أبواب القاعات)، تربطها **ممرات** مستقيمة طول كل منها بالأمتار من قياس الفريق. كل **مكان** (قاعة، مكتب، مرفق، درج، مصعد...) يقع عند نقطة. **الدرج والمصاعد** تربط الطوابق داخل المبنى، و**الممرات بين المبنيين** تربط طابقاً في مبنى بطابق في الآخر.

## الملفات

| الملف | ما فيه |
|---|---|
| `buildings.json` | المباني: `B1` و`B2` |
| `floors/B1-G.json` | طابق واحد: نقاطه وممراته وأماكنه. ملف لكل طابق، واسمه المبنى ثم حرف الطابق |
| `links.json` | الدرج والمصاعد بين الطوابق، والممرات بين المبنيين |
| `doctors.json` | الدكاترة ومكاتبهم |

## الرموز

- **المبنى:** `B` ثم رقمه: `B1`، `B2`.
- **الطابق:** المبنى ثم حرف الطابق: `B1-G` (الأرضي)، `B1-F` (الأول)، `B1-S` (الثاني). الطابق الثالث لا يدخل في البيانات.
- **القاعة والمعمل والمكتب:** رمز الجامعة `B1-F215`: الطابق ثم رقم الغرفة بلا شرطة.
- **المرافق والمداخل والدرج والمصاعد:** الطابق ثم شرطة ثم اسم قصير بحروف وأرقام إنجليزية: `B1-G-WC1`، `B1-F-ST1`.
- **النقطة:** الطابق ثم نقطتان ثم اسم: `B1-G:p3`.

## ملف الطابق

```json
{
  "id": "B1-G",
  "building": "B1",
  "level": "G",
  "map": null,
  "width": 1000,
  "height": 600,
  "demo": true,
  "points": [
    { "id": "B1-G:p1", "x": 100, "y": 300 },
    { "id": "B1-G:p2", "x": 200, "y": 300 }
  ],
  "corridors": [
    { "from": "B1-G:p1", "to": "B1-G:p2", "length_m": 4.9 }
  ],
  "places": [
    { "id": "B1-G101", "kind": "room", "point": "B1-G:p2", "demo": true },
    { "id": "B1-G-WC1", "kind": "facility", "name": "دورة مياه الرجال", "point": "B1-G:p1", "demo": true },
    { "id": "B1-G-EN1", "kind": "entrance", "name": "المدخل الرئيسي", "point": "B1-G:p1", "landmark": true, "demo": true }
  ]
}
```

- `map`: صورة الخريطة داخل `public/`، مثل `"maps/B1-G.png"`. تبقى `null` حتى تصل الصورة.
- `width` و`height`: أبعاد صورة الخريطة بالبكسل. `x` و`y` لكل نقطة موضعها على الصورة: `x` من اليسار و`y` من الأعلى.
- `length_m`: **الطول الحقيقي بالأمتار من قياس الفريق** (عدّ البلاط)، وهو المرجع للمسافات. البكسل للرسم فقط.
- `kind` (نوع المكان): `room` قاعة، `lab` معمل، `office` مكتب، `facility` مرفق، `entrance` مدخل، `stairs` درج، `elevator` مصعد.
- `name`: مطلوب لغير القاعات والمعامل والمكاتب. للقاعة يكفي الرمز.
- `landmark: true`: يظهر المكان في قائمة المعالم التي يختار منها الطالب موقعه.

## links.json

```json
{
  "vertical": [
    { "id": "B1-ST1", "kind": "stairs", "stops": ["B1-G-ST1", "B1-F-ST1", "B1-S-ST1"], "demo": true }
  ],
  "passages": [
    { "id": "B1-B2-G", "name": "الممر بين المبنيين في الطابق الأرضي", "from": "B1-G:p9", "to": "B2-G:p1", "length_m": 18.6, "demo": true }
  ]
}
```

- `vertical`: كل درج أو مصعد، و`stops` أماكنه في الطوابق التي يقف عندها (مكان من النوع نفسه في كل طابق).
- `passages`: ممر يربط نقطتين في طابقين مختلفين، مثل الممر بين المبنيين، وطوله بالأمتار.

## doctors.json

```json
{ "doctors": [{ "id": "d1", "name": "د. أحمد التجريبي", "office": "B1-F210", "demo": true }] }
```

`office` رمز مكتب موجود في ملفات الطوابق (نوعه `office`). يمكن أن يشترك أكثر من دكتور في مكتب.

## ما يفحصه الفحص الآلي

**أخطاء توقف النشر:**
- حقل ناقص، أو بنوع خاطئ (مثل `"demo": "true"` بعلامات تنصيص)، أو باسم غير معروف (خطأ إملائي مثل `lenght_m`).
- رموز بغير النمط أعلاه، أو رمز في ملف طابق غير طابقه، أو طابق غير `G`/`F`/`S`، أو معرّف مكرر.
- ممر أو مكان يشير إلى نقطة غير موجودة، أو طوله صفر.
- ممر مائل أكثر من 10°: الممرات متعامدة، فالميل غالباً خطأ في الإحداثيات.
- نقطة لا يمكن الوصول إليها من بقية الكلية، أو درج أو مصعد لا يربطه شيء بطابق آخر.
- مكتب دكتور غير موجود أو ليس من النوع `office`.
- عنصر حقيقي (`"demo": false`) يشير إلى عنصر تجريبي.

**تنبيهات (لا توقف النشر، لكن راجعها):**
- ممر طوله بالأمتار لا يتسق مع طوله على الخريطة (فرق أكثر من 25% عن بقية ممرات الطابق): غالباً خطأ في العدّ أو الإدخال.
- لا يوجد أي معلم.
