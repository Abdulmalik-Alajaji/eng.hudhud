# هدهد الهندسة

موقع يساعد طلاب كلية الهندسة على الوصول لأي قاعة أو مكتب دكتور أو مرفق داخل الكلية، بدون GPS ويعمل بدون نت بعد أول فتح.

- الموقع: https://abdulmalik-alajaji.github.io/eng.hudhud/
- حالة العمل: [PROGRESS.md](PROGRESS.md)
- قواعد المشروع: [CLAUDE.md](CLAUDE.md)

## التشغيل محلياً

```bash
npm ci
npm run dev      # خادم تطوير محلي
npm run verify   # كل الفحوص: الأسرار، الأنواع، الاختبارات، البناء، الحجم والأمان
```
